# 弦栖霁

Windows PC + 安卓本地音乐播放器，当前版本 v1.0.14。采用原创暖色界面。升级前先从托盘退出旧版，勿同时访问同一音乐库。Windows 使用安装目录旁的 Data 保存全部应用数据，旧版数据库会复制校验迁移；迁移后请使用新版，旧版不能直接读取新文件库，降级前请先导出 ZIP。

## 本版新增

### v1.0.14：本地强对齐与有界自动队列

- 增加独立的强对齐地址、模型别名、加密密钥和连接配置导入；保留原翻译配置，可测试连接。手动结果先进入草稿，支持重新生成旧逐字时间。
- 默认手动；桌面端可主动开启自动处理，最多两首并发，只补缺失或旧聊天估算，跳过有效实测时间。检查 Windows 与服务端资源，服务停止或繁忙时等待；失败记录持久化，取消与曲库切换不覆盖旧数据。
- [部署文档与一键脚本集中在 local-aligner](local-aligner/README.md)，复用 `E:\work\model\Qwen3-ForcedAligner-0.6B`，现已切换为 Windows 原生 PyTorch / Transformers 与官方 qwen-asr，无需 WSL。准备、启动、停止均有独立入口，运行文件归入该目录 `runtime/`。
- 本机部署文件已统一放在 `E:\work\model\local-aligner`；项目中的 `local-aligner` 为目录链接，实际文件、配置与运行环境只在模型目录保存一份。
- 首次使用按部署文档准备独立 Windows Python 与 CUDA 依赖，不修改播放器协议，现有 1.0.14 客户端可直接连接原生服务。

### v1.0.13：重新生成已有逐字时间

- 歌词设置增加「AI 重新生成整首」，已有逐字时间的句子也重新计算，不再因已处理而跳过；当前句已有时间时显示「AI 重新生成本句」。补齐缺失时间仍有独立入口。
- 重新判断旧的唱完时间和间奏，避免旧错误结束时间限制新结果；本次编辑中手动修改的开始、唱完时间保留为约束。原文、中文不变，结果先预览，保存后生效。
- 未匹配句子保留原时间并显示数量；失败、取消或放弃草稿保留已保存的数据。继续禁止后台自动 AI。

### v1.0.12：唱完时间与间奏

- 歌词设置新增「本句唱完时间」，与下一句开始分开，可边听边采点；缩短时只收紧超出范围的逐字草稿。唱完后的间奏不再计入整句或逐字高亮，下一句仍按原开始时间切换。
- 手动 AI 生成先判断唱完时间及后续间奏，再分配字词时长；聊天结果标注估算和试听提示，音频识别保留最后一个字的实际结束，并拒绝跨句或重叠结果。仍无自动 AI 调用，生成后需点击保存。
- 曲库 JSON 使用句级 `endTime`；增强 LRC 使用行内 `[x-end:00:04.000]` 保存唱完时间，字词继续使用 `<00:01.000>` 标记。导入、导出及曲库同步均保留间奏边界。

### v1.0.11：手动逐字校准与主动 AI 生成

- 移除后台自动逐字 AI，旧版已开启的配置也会停用；启动、导入、切歌、保存 AI 配置和失败重启均不自动提交生成请求。
- 在完整歌词页或偏好设置中打开「歌词设置」，选择歌曲和句子，直接调整每字的开始、结束时间；可播放所选歌曲、定位到某字，并用当前播放时间采点，手机端也可使用。
- 缺少逐字时间时先展示可编辑草稿，只有点击「保存歌词时间」才写入增强 LRC 和曲库；原文和已有中文保留。未保存的修改可还原或关闭放弃；拒绝无效、重叠或越界时间，并防止覆盖已经变化的原文。
- 需要时主动点击「AI 生成本句」或「AI 生成整首缺失时间」。整首生成跳过已有逐字时间，生成本句可重新估算当前句；聊天模型继续分析唱法、停顿和拖音，音频识别仍可选择。生成先进入草稿，可校准后保存，不自动替换音乐库。
- `scripts/check-lyric-settings.cjs` 和 `--text` 使用隔离库、模拟接口验证旧自动标志停用、保存配置零调用、手动编辑落盘、主动 AI 草稿、保存与取消、已有时间零调用及重启不自动重试。

### v1.0.10：逐句轮换与时间边界

- 桌面双句歌词逐句轮换：下一句开始时立即把已唱完的位置换成后续歌词，横竖排一致。
- 聊天 AI 返回唱法时长与停顿比例，由本地程序分配到原句区间，修复可恢复的越界、重叠和倒序；估算标记保留。

### v1.0.9：独立安装临时环境

- 修正播放器重定向 TEMP/TMP 后，安装器和旧卸载器仍留在 Data/Temp 内被进程清理误伤的问题；所有安装子进程改用独立临时环境，并加入完整隔离 NSIS 升级回归。

### v1.0.8：修复退出并安装

- Windows 不再从程序自己的 Data/Updates 直接执行安装包，先复制到独立系统临时目录并重新校验，通过后启动可见安装向导并退出播放器。启动失败保留播放器和下载，拦截重复启动。
- 新安装包兼容旧版启动方式，先转到临时目录并保留完整目标路径与参数，避免安装器把自己当成安装目录内的进程关闭；保留当前安装路径、Data、曲库和 AI 配置。
- `scripts/check-update-handoff.cjs` 使用真实 NSIS 小安装器，在隔离目录复现旧流程并验证旧版启动、新版临时副本、中文 / 空格路径以及数据保留，不操作实际用户音乐库。

### v1.0.7：默认时间与聊天 AI 估算

- 普通 LRC 默认恢复整句匀速高亮，已有字词时间的按字词高亮。
- 保存 AI 配置后默认复用现有聊天模型（可用 DeepSeek）分析唱法、停顿、重音和拖音，在原句时间内估算字词时间，可填写唱法提示。只发送歌词和歌曲信息，不上传音频；估算不保证与录音精确同步，可能产生文本费用。
- 估算结果标注“AI 估算时间”，写入增强 LRC 的 `[x-timing:estimated]` 标记及完整曲库元数据；ZIP、单独 LRC 导入和私人曲库保留此标识。保留原句时间、原音频和中文译文，已有有效逐字时间的跳过。音频模型识别仍可手动选择。
- 请求前记录检查点，失败和重启不反复自动收费重试；修复根地址多出斜杠。`scripts/check-auto-alignment.cjs --text` 用模拟 DeepSeek 验证完整流程，不调用用户的付费服务。

### v1.0.6：AI 逐字歌词跟唱（下述默认方式在 v1.0.7 调整）

- 修正桌面歌词将整句均速涂色当作演唱进度的问题。有真实逐字时间戳时，主窗口与桌面歌词均按各字词的开始、结束时间高亮，支持快唱、停顿和拖音；普通 LRC 仅整句高亮，不再伪造逐字进度。中文译文单独显示，不套用原文的字词时间。
- 「单独导入歌词」及 ZIP 同名歌词支持增强 LRC（`[00:01.000]<00:01.000>我<00:01.300>们<00:03.000>`）和 YRC（`.yrc`）；无需重新导入音频。逐字时间随完整音乐库、ZIP 导出和私人曲库同步保留，Windows 同名 LRC 副本也保存逐字标记。
- 「偏好设置 → AI 逐字歌词」复用现有 AI 服务地址和密钥，单独填写支持字词时间戳的音频模型（默认 `whisper-1`）。勾选自动生成并保存配置后，串行检查本地歌曲：已有有效逐字时间轴的跳过，缺少时才上传音频至同一服务的 `/audio/transcriptions`。普通文本翻译模型不能提供真实唱字时间，DeepSeek 官方文本服务会在上传前提示不支持。
- 使用音频模型返回的起止时间与现有原文完整匹配，保留原文及中文译文；匹配到的句子自动写入曲库及增强 LRC。模型只返回词级时间时按词显示，不均分伪造逐字时间。未匹配句子保留原样并记录状态，不反复收费重试；服务失败时停止本轮，重新配置或手动重试后继续。每次提交前保存检查点，重启不重复提交未确认的请求；暂停仍可能产生在途费用。全自动流程不处理尚无原文或仅云端点播的歌曲。
- 直接上传支持格式且小于 24 MB 的音频；较大的普通音乐或不支持的格式会在本机尝试转为 16 kHz 单声道 WAV，原音频不修改。当前拒绝准备超过 160 MB 的源文件、转换后仍超出上传上限的长录音；服务端可能有更小的限制。安卓前台运行，安卓 / 浏览器需要服务允许跨域。识别歌曲的准确性取决于人声、伴奏和模型，建议听歌核对；未加入人声分离或音素级强制对齐模型。
- 播放中更频繁读取真实音频时钟；暂停、拖动进度和缓冲时停止错误推进。
- `scripts/check-word-lyrics.cjs` 使用独立测试库验证真实播放、YRC 单独导入、逐字文件落盘、桌面浮窗 IPC、暂停和拖动后的位置，以及横竖排高亮；不读取实际用户曲库。
- `scripts/check-auto-alignment.cjs` 在真实 Electron 中用固定音频识别返回，验证保存 AI 配置后自动检查、已有逐字的零调用跳过、缺失的串行生成、增强 LRC 落盘、中文保留以及重载后的零重复请求；不调用付费 AI。协议依据 [OpenAI 音频时间戳文档](https://developers.openai.com/api/docs/guides/speech-to-text#timestamps)，第三方兼容服务须自行提供对应模型与能力。

### v1.0.5

- PC 更新安装改为可见向导，不再静默隐藏；旧版自身的更新逻辑仍需先升级一次。安卓云端流播放加入原生后台队列，缓存可能在系统恢复前台后完成，尚需手机实测。

此前版本功能：

- Windows 设置加入「打开已有音乐库」：直接选择有效文件库或它的 Data 父目录，预览路径和歌曲数，完整核验音频 / 封面哈希后切换并刷新，不复制、不合并、不覆盖目标。保留当前播放器设置及系统加密密钥，原库不删除，可随时切回。已有库不混入本机遗留 IndexedDB 的歌曲与缓存；原配置目录失联时也能选择另一份有效库。详情见 `docs/音乐库使用.md`。

- 偏好设置加入「软件更新」：Windows / 安卓可自行填写域名或完整 HTTPS 更新目录，保存后检查版本、阅读说明、暂停 / 继续下载并确认覆盖安装。默认手动检查，可开启启动后每天最多检查一次；不会自动下载或安装。便携版下载后手动替换启动器，保留 Data。首次从 v0.3.9 升级需要手动安装一次新版。
- 更新强制校验 HTTPS、内置发布公钥的 RSA-SHA256 签名、文件大小和 SHA-256，拒绝篡改或降级；安卓还检查包名、versionCode 及 APK 签名。IP HTTPS 更新服务已部署，域名和证书更换、发布密钥备份、日常发布、目录与维护命令详见 `docs/构建与发布.md`。签名私钥只保存在开发电脑，不进入软件或服务器。

- 安卓接入原生 MediaPlayer + MediaSession 前台播放服务，队列推进、循环 / 随机、音量渐变和睡眠停止在原生端执行，不依赖锁屏后的 WebView 事件。首次播放会在前台准备并 SHA-256 校验当前队列的原音频副本，完成提示后再锁屏；副本在应用私有的 playback-audio，下次复用，需要相应额外空间。通知栏支持上一首、播放 / 暂停、下一首和停止服务；耳机断开自动暂停，支持音频焦点。强制停止应用或厂商杀进程仍会停止播放。
- 修复手机版播放模式按钮被 CSS 隐藏；底栏、详情与「播放全部」右侧均可切换列表循环 / 随机 / 单曲，状态统一且重启保留。
- 修复安卓原生导出把 JSON Integer 偏移量当 Long 读取导致空值的问题，覆盖 0、4 MB 和大于 4 GB 的 ZIP64 偏移。完成后通过系统「另存」选择实际目录，不再依赖分享应用才能保存；取消另存不会删除内部音乐包。
- 加入睡眠定时（1–1440 分钟），可选到时立即停或播完整首再停；不会继续下一首或触发单曲循环。播放 / 暂停默认 0.5 秒淡入淡出，可选关闭、0.3、1、2 秒，保持用户音量设置，允许快速反向切换。
- Windows 全局快捷键列表可开关、录入组合、清空、恢复默认、保存及查看实际注册状态；重复或被其他应用占用显示冲突，隐藏到托盘仍生效。仅包含已实现的播放、切歌、音量、收藏、窗口、桌面歌词与模式动作，不提供虚假的听歌识曲入口。
- AI 密钥在 Windows / 安卓默认加密保存并重启读取，修复每次打开配置页面默认不记住而清除密钥、以及异步加载未更新表单的问题。Windows 为 Data/ai-config.json（DPAPI 密文），安卓为 no_backup/config/ai-config.json（Keystore AES-GCM 密文），配置页面展示实际路径；配置文件不包含解密用的系统密钥，音乐包不导出 API Key。
- Windows 首屏仅读取元数据与封面，不再串行读取并计算全部歌曲音频 SHA-256。播放使用带 Range 的本地流，首次播放单曲仍校验该文件，导出按块读取。新增轻量开屏动画，最多 3.5 秒自动离场，不阻塞操作，并遵守系统减少动态效果设置。
- Windows 新增真正的 NSIS 安装包 `Xianqiji-Setup-0.3.8-x64.exe`，安装向导可选择目录，首次默认 `E:\game\music`。歌曲、歌词、译文、IndexedDB、缓存、设置与系统加密 Key 默认统一保存在该目录的 `Data`，不再默认往 C 盘用户目录写音乐数据。升级和卸载仅移除已知程序文件，保留 Data 与用户备份；不包含 Windows 管理的安装临时文件、快捷方式和注册表。
- 「导入音乐」新增「单独导入音频」与「单独导入歌词」。支持 LRC / TXT 原文、中文文件和双语 LRC，保存前选择对应歌曲、文件用途并预览；唯一同名自动匹配，同名多版本需手动确认。纯歌词拖入也打开匹配窗口，不要求重新导入音频，保存后同步写入文件音乐库。
- Windows 偏好设置新增「音乐库保存路径」：查看、打开目录，选择新位置并复制切换。逐文件 SHA-256 校验后才更新目录配置，旧目录保留作备份，不覆盖非空目标目录。
- 歌曲、封面、原文 LRC / TXT、中文 .zh.lrc / .zh.txt、完整歌词和译文核对资料、翻译缓存统一保存。AI 翻译、下载歌词和人工校对后自动落盘；重复导入相同音频和相同原文时保留已有中文。
- 首次升级将内部 IndexedDB 的歌曲和译文缓存迁移至文件音乐库，校验成功后清理旧数据库记录；失败保留原记录。目录或磁盘缺失会明确报错，不偷偷创建空库。浏览器仍使用私有数据库；安卓 v1.0.2 起可主动复制到自选文件夹，或打开已有文件库，原内部库保留。
- 桌面歌词默认自动显示中文：有译文时只显示当前原文和紧贴的中文，字号一致，横排原文在上、中文在下，竖排原文在右、中文在左并垂直居中。独立于主窗口的译文开关；没有译文时显示当前句与下一句原文，每句开始时将已唱完的位置换成后续句，两行交替高亮，不会自动联网或消耗 token。升级旧设置时自动启用，仍可手动切换纯原文双句或仅原文＋译文。
- 无译文双句按参考图采用句尾接续：横排下一句在下一行，从上一句末尾右侧留白后开始；竖排下一句在左列，从上一句末尾下方留白后开始。按浏览器实际文字尺寸布局，不再使用固定错位量。默认句尾空约 3 字，可在偏好设置调为 1–6 字；窗口放不下时整组等比缩小，字号缩小时不会把两句拉远。原文与译文仍固定贴近，不使用句尾接续留白；只剩一句时不预留空白的下一句位置。
- AI 翻译明确歌曲及专辑版本、原文在全曲中的行号和重复出现位置，翻译与独立校对均携带上下文；长歌词不再仅截取开头，而是提供待译段落前后文。增加手动「重新翻译已有中文」，额外计费且绕过旧缓存，核对通过后才替换，失败保留原文时间轴与旧译文。
- Windows 托盘右键面板支持播放暂停、上一首 / 下一首、收藏、播放模式、音量、歌词开关、打开主窗口、偏好设置和退出。
- 偏好设置加入「关闭主面板」：默认最小化到托盘，不退出程序，也可选择退出程序。自动保存，右上角关闭按钮直接按选择执行，不再弹出原生询问框。托盘内「退出弦栖霁」始终直接退出。

- 导入逐首保存检查点，暂停 / 退出后到「传输任务」重新选择同一源包继续，跳过已完成歌曲；尚未完成的单首歌曲重新读取，并非压缩流内部逐字节续解压。
- 导出使用标准 ZIP64、4 MB 分块随机写入，写盘成功后保存偏移和 CRC 状态。中断后从已确认的块继续，不必从头生成。Windows 直接写入所选位置；安卓写入应用私有目录，完成后通过系统分享另存或发送。
- 移除旧的 ZIP 1 GB / 展开 2 GB / 5000 条目总量限制。不代表无限空间：仍受磁盘余量、文件系统、浏览器配额、设备内存和单首音频能力约束；ZIP64 避免传统 ZIP 的 4 GB 限制。
- AI 配置只保留服务地址、模型和密钥，不再需要 token 预算、最多句数、输出上限控件。
- 翻译请求明确歌名、歌手、专辑和原文上下文；先翻译，再发起独立校对请求，检查歌曲身份、原文、行号及译文语义。仅保存核对通过的批次，并保留原时间轴。
- 原文 / 中文对照核对表，允许人工修正并保存，详情页和桌面歌词同步使用保存后的译文。
- 按本机月份变化的四季氛围：春花、夏萤、秋叶、冬雪；可手动切换或关闭，遵守系统减少动态效果设置。按北半球气象季节划分，3–5 / 6–8 / 9–11 / 12–2 月。
- 软件新名称「弦栖霁」（Xianqiji）。2026-10-15 公开精确名称检索未发现同名音乐软件，不保证全球未使用或商标可注册。

## 使用

1. 运行 Setup 安装包选择目录。点击「导入音乐」选择 ZIP，或点击「单独导入音频」「单独导入歌词」。歌词先确认对应歌曲与原文 / 中文用途，再保存；无原文时不能把中文文件误当原文自动覆盖。
2. 点击歌曲开始播放；底部封面进入详情歌词页，可拖动进度条。Windows 独立置顶桌面歌词支持悬停菜单、工具名称提示、横排双行 / 竖排双列切换、配色、字号和播放控制。横排采用左上 / 右下错位双句，菜单在顶部居中；竖排采用右上 / 左下错位双列，菜单沿左侧纵向排列。双句模式每两句固定显示，当前句在两句间交替高亮；也可通过齿轮菜单切换为原文与中文译文。
3. 缺少歌词时点「联网补全」，查询 LRCLIB，核对歌手、专辑、时长和预览，选择正确版本。查不到时不会编造原文，也不自动转录音频。
4. 缺少中文时，在偏好设置填写自己的 DeepSeek 或其他兼容 Chat Completions 服务和 Key，再手动翻译；免费 MyMemory 为可选备用，可能限额。
5. 「导出音乐」选择歌曲，首次选择保存位置。暂停 / 重启后在「传输任务」继续。未完成前勿删除源歌曲、移动或修改导出半成品。
6. 导出完成后，PC 可打开保存位置，安卓点「保存位置 / 分享」使用系统文件应用另存到公共目录。将 ZIP 复制到新设备再导入，恢复原音频、封面、双语歌词、收藏、来源与译文核对记录。

本功能是本地导入 / 导出任务的断点恢复，不是网络文件上传 / 下载的 HTTP 断点续传。源包拷贝到另一设备的过程由所选传输工具负责。删除任务记录不会删除用户已导出的 ZIP。安卓应用内中间文件会占用额外空间，卸载或清理应用数据会删除音乐库和尚未另存的导出文件。

## 音乐库路径与保留

v0.3.8 默认为 `<安装目录>\Data\音乐库`，例如 `E:\game\music\Data\音乐库`；开发模式使用项目 `.dev-data`，便携版使用启动器旁的 Data。在「偏好设置 → 音乐库保存路径」可查看音乐库和全部应用数据的完整路径、打开文件夹，或仅为音乐库选择新的父目录。程序将在选择的位置创建「弦栖霁音乐库」子目录；点「复制并切换音乐库」后，会复制并校验全部已保存文件和缓存，再切换路径。旧目录先保留，确认正常后可自行清理；它不会与新目录自动同步。目标非空或校验失败时不切换，也不覆盖原数据；失败的目标半成品需自行清理或改选空目录。

```text
弦栖霁音乐库/
├── library.json                 完整曲库、收藏、时间轴、来源与译文核对资料
├── translations-cache.json      翻译缓存（有缓存后生成，不含 API Key）
└── 歌曲/<歌曲指纹>/
    ├── 歌手 - 歌曲.mp3          原音频，不转码
    ├── 歌手 - 歌曲.lrc          原文；纯文本为 .txt
    ├── 歌手 - 歌曲.zh.lrc       中文；纯文本为 .zh.txt
    ├── cover.jpg                有封面时保存，格式也可为 PNG / WebP
    └── tingyu-library.json      该曲完整元数据
```

新库使用完整 `library.json` 作为索引；原文和中文文件是可直接查看的副本。下载歌词、AI 翻译、人工核对与收藏修改后自动同步保存。直接修改副本不会自动更新索引，请通过软件核对表修改或重新导入。原 ZIP 不会被修改；没有中文的曲目会保留空中文文件，取得译文后自动写入。不需要重新翻译已保存内容，查看目录或复制音乐库不消耗 AI token。

偏好设置、系统加密的 API Key（若启用）、导入导出任务索引与 Chromium 数据库 / 缓存也默认在 `<安装目录>\Data`，新库位置记录在其中的 `library-location.json`。系统加密 Key 跨电脑可能无法解密，请在新设备重新填写。音乐库路径选择仅移动音乐文件，不移动全部 Data；初次选择安装路径则决定全部 Data 的默认位置。默认导出在 `Data\导出`，可以在保存对话框另选位置。没有自动云同步。

初次发现旧 C 盘数据且新 Data 不存在时，会要求先退出旧版，再完整复制到新 Data，并生成同级的旧数据备份与迁移记录，逐文件 SHA-256 校验；不会自动删除 C 盘目录。维护工具 `scripts/migrate-profile.cjs copy <旧目录> <新目录>` 可在退出播放器后执行同样的复制，目标非空时拒绝覆盖。`cleanup <迁移记录> <确认的旧目录>` 仅在新文件库存在、旧源与独立备份均再次校验通过时清理精确旧目录；务必先运行新版确认曲库可用。此工具不清理系统其他缓存或应用数据。

迁移大库请保证空间足够，勿退出或移除磁盘；完整复制和备份会暂时占用两份空间。程序采用分块传输与文件哈希校验，但播放器仍需按当前库载入音频，不能承诺任意大小音乐库均不受内存限制。

安卓 / 浏览器继续使用应用私有 WebView / 浏览器数据库，不能在本版直接更改该内部路径；歌词和译文会随歌曲持久保存。需要可见文件或换设备时使用音乐包导出，安卓通过系统文件应用另存到指定位置，卸载或清理应用数据前务必备份。

## 翻译质量与费用

服务地址默认 https://api.deepseek.com，模型默认 deepseek-flash，可改为服务商实际支持的模型。接受 HTTPS 根地址、/v1 或完整 /chat/completions 地址。

- 默认只补全缺失译文，重复句去重。已核对缓存按提示词版本、服务、模型、语言、歌曲身份、原文上下文与句子隔离，避免同一句在不同歌曲里错误套用。已保存的旧译文不会自动重翻；需要更新时手动勾选「重新翻译已有中文」并点击翻译，不复用旧缓存，可能增加费用。
- 自动按文本量分批，不设置用户级预算 / 句数 / 输出 token 限制；服务商本身的上下文和输出限制仍存在，被截断的批次不保存。
- 校对也会调用模型，通常每个新批次需要两次请求，比只翻译一次费用高；保留自动去重与缓存以减少重复费用。
- 仅发送歌曲信息与歌词文字，不上传音频、封面、时间戳。只有点击翻译才调用 AI，配置保存不消耗 token；无自动付费重试或免费到付费切换。
- 显示服务返回的输入 / 输出用量，无法获取时明确未知；取消在途请求仍可能计费。
- 结构和原文校验是程序完成的，译意复核由所选 AI 完成，并非真人审校，不能保证零错译。重要译文请使用对照核对表修正。
- 明确歌名能减少同名歌和版本混淆，但准确性仍依赖给定原文、上下文与模型；其他平台可能使用意译或不同版本，措辞不同本身不能说明对错。程序核对歌名、歌手、专辑、原文和行号，模型复核语义，不能自动认证等同官方译文。
- Windows / 安卓默认使用系统加密并保存密钥；取消「加密保存」后保存配置会清除已存密钥，仅留在本次运行内存。浏览器预览不提供系统密钥保存。音乐包不含 Key 或服务配置，系统密钥不能跨设备迁移，换设备需重新填写。

接口说明：[LRCLIB](https://lrclib.net/docs)、[MyMemory](https://mymemory.translated.net/doc/spec.php)、[DeepSeek JSON 模式](https://api-docs.deepseek.com/guides/json_mode/)。

## 音乐包

支持 MP3 / FLAC / WAV / M4A / AAC / OGG / OPUS，编码能否播放取决于系统 WebView / Chromium。

```text
我的音乐.zip
└── 专辑/
    ├── 歌手 - 歌曲.mp3
    ├── 歌手 - 歌曲.lrc
    ├── 歌手 - 歌曲.zh.lrc
    └── cover.jpg
```

原文与中文分别使用同名 LRC；中文后缀还支持 .zh-cn.lrc、.translated.lrc、.cn.lrc、.zh.txt。LRC 按时间戳匹配，TXT 按行匹配且不支持同步定位。单个 LRC 可在相同时间戳分别写原文与中文。支持 UTF-8、UTF-16 BOM、GBK / GB18030。可用内嵌封面、同名图片或同目录 cover / folder 图片。RAR / 7Z 需先转换成 ZIP。

导出时音频原样复制，不转码；每首目录含标准歌词及兼容文件名 tingyu-library.json，内容使用 xianqiji-library 格式，按音频 SHA-256 匹配完整元数据。仍可导入旧 tingyu-library 清单。歌词或译文单独更新时可使用「单独导入歌词」，无需重新导入音频。原文按文本保留匹配的旧译文；中文按时间戳（TXT 按行）匹配，同一首只能同时选一份原文和一份中文，防止静默覆盖。

## 限制

- 本地库而非网易云 / QQ 音乐曲库，不提供未经授权的音源下载。
- 暂不云同步；卸载、清理应用数据前须自行完成备份。
- 安卓在首次后台音频准备完成后使用原生前台服务，锁屏连播仍需实际手机验证，部分厂商需取消电池限制；系统强制停止会终止播放。首次准备副本需额外空间；准备未完成时请保持前台。桌面歌词独立浮窗与全局键盘组合仅为 Windows 功能。
- Windows 安装包与便携版未进行商业代码签名；安卓为不可调试的 Release APK，但为兼容覆盖升级保留早期开发证书身份，当前仅自托管发行。安卓文件选择、分享、超大文件及各系统编码兼容性尚需实机验证。安卓安装及内部数据路径由系统决定，不支持 Windows 的自选安装路径。
