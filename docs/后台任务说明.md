# 后台任务说明（v1.0.18）

## 使用方式

任务启动后直接关闭其窗口即可继续听歌、搜索或进入其他页面。侧栏「传输任务」打开统一任务中心，也可点播放器上方的后台任务提示。关闭任务中心不会暂停任务；显式点「暂停任务」「暂停并保存进度」或「暂停全部任务」才会请求暂停，正在发送的网络请求和提交步骤可能需要等待安全边界。

- 下载 / 补充到本地、手动上传：保存所选歌曲 ID 和每首完成检查点。暂停 / 失败 / 重启后点「继续传输」，跳过已完成歌曲。当前未完成的下载歌曲重新读取、校验，不能宣称单首下载支持字节级续传。上传继续复用原分块检查点和 SHA-256 去重。
- ZIP / 单独音频导入：关闭窗口继续；退出后需重新选择同一批原文件，已完成歌曲跳过。
- 导出及恢复导出：关闭窗口继续写 ZIP64，任务中心可暂停、恢复、定位或在安卓另存已完成的包。系统保存位置选择器需要返回前台手动操作，不在锁屏时强行弹出。
- 联网歌词、翻译及主动生成逐字时间：已启动请求关闭窗口后继续，任务中心返回原窗口。译文仍按原保存流程处理；手动逐字结果保留为草稿，必须核对后点击「保存歌词时间」，不会因转后台直接覆盖时间轴。未保存草稿不承诺在进程被杀或页面重载后恢复。
- 自动上传、点播缓存、主动开启的自动本地强对齐、更新下载及目录复制仍有各自的控制入口，运行进度纳入任务中心。切换曲库、修改音源和安装更新会避开正在运行的相关任务。

传输检查点仍由应用数据库保存，安卓按所选音乐库隔离；音源任务还核对完整的库身份和音源地址 / 密钥摘要。任务日志只记录标题、类别和状态，不保存 API Key、曲库密钥、音频或整个音乐库。下载仍写入设置中当前的本地音乐库，不另设长期音频缓存目录。

## PC

关闭弹窗或隐藏主窗口到托盘后继续。真正退出程序或关闭电脑会中止进程，不能离线执行；下次通过检查点手动恢复。付费 AI 请求中断后不会自动重发，已经提交给服务商的请求仍可能产生费用。

## 安卓锁屏与切换应用

v1.0.17 的前台服务只保活应用，具体下载循环仍在 WebView。红米实测发现切到后台后下载进度冻结、回前台继续，所以不能用「服务仍在」或「关弹窗后继续」来证明真正后台下载正常。

v1.0.18 在**已选择手机文件夹**的模式下，将手动「下载 / 补充到本地」整批队列交给原生 Java 执行。网络请求、逐块下载、SHA-256、逐首提交与检查点都不等待 JavaScript 回调；直接写入当前授权的文件音乐库，不另设长期音频缓存。已存在音频不重新下载，只补缺失内容，保留本地已有译文、收藏、加入时间、逐字和唱完时间。下载过程中如本地歌词改变，提交时重新合并，避免覆盖新改动。

通知栏的下载进度及「暂停全部」也由原生处理。任务清单在应用私有 no_backup/source-download-tasks 保存非敏感检查点，只有歌曲 ID、曲库 / 音源身份摘要和状态，不含访问密钥或音频；密钥只在本轮原生下载内存使用。每首确认写库后才记录完成，强杀后手动继续跳过完成项；当前未完成歌曲仍重新读取校验，不是字节级续传。

默认 IndexedDB 内部库，以及上传、导入、导出、AI 等其他类别仍含 WebView 调度，没有全部重写为独立原生队列；不能据此承诺它们在所有手机的锁屏 / 后台继续。不会为了修复下载而偷偷迁移内部曲库、另选目录或重新导入你的文件。

运行任务使用「后台传输与处理」前台服务、常驻通知和有界续期的 CPU 唤醒锁，不需要假装一直播放音乐。多个任务共用一个服务，全部结束后停止服务并释放唤醒锁，不设置开机自启，不在系统杀进程后自动重放任务。

首次运行请允许任务通知。通知栏支持暂停全部，任务中心提供系统电池设置入口；厂商系统可能还需手动允许后台运行或设为不限制。软件只打开设置，不擅自更改系统策略。新任务应在应用前台主动启动；后台没有活动服务时不会绕过系统限制强行启动新的前台服务。

Android 15 及以上对 dataSync 前台服务有累计运行时限；收到系统超时回调时服务停止、通知任务暂停，已完成内容与检查点保留，不自动重发付费 AI。强制停止、从最近任务划除、断电、失去存储授权、拔卡或网络中断仍可能结束任务，需要重新打开并核对后继续。详见 [Android 官方前台服务时限说明](https://developer.android.com/develop/background-work/services/fgs/timeout)。

当前 Capacitor 的 KeepRunning 默认启用，WebView onPause 不等于暂停 JavaScript；原生前台服务与唤醒锁用于支撑已启动任务，不代表完整脱离进程的 headless 执行。不能保证系统强杀后仍在下载。参见 [Android WebView 生命周期 API](https://developer.android.com/reference/android/webkit/WebView#onPause())。

## 验证

### 红米实测（尚待用户手机确认）

1. 先在任务中心暂停旧下载，安装 v1.0.18 APK 覆盖旧版，不卸载、不重新选库。确认设置中原来的音乐库文件夹仍可访问。
2. 新建或继续一批「下载 / 补充到本地」。通知栏应出现「原生后台下载」及歌曲 / 百分比。切到其他应用 1–2 分钟，不返回播放器，观察通知栏是否从当前歌曲继续到后续歌曲。
3. 再锁屏 2–3 分钟。解锁后检查通知栏或已完成歌曲数，返回播放器核对歌曲已在原文件夹、原译文和收藏保留，并可离线播放。
4. 在通知栏点暂停，确认不再继续下载；回任务中心继续，应跳过已完成歌曲。强制结束进程后，必须手动继续，不自动重发 AI。
5. 如系统仍终止服务，请允许任务通知，在红米应用电量设置中设为「无限制」并允许后台；这些是系统策略辅助，不能替代原生下载修复。请记录手机型号、HyperOS / MIUI 版本、锁屏前后歌曲数量与通知变化。

目前未连接手机，只有原生 JVM 队列、编译和隔离界面验证，不能声称已在红米锁屏通过。

测试只使用隔离音乐库和模拟 AI，不读取实际用户音乐库或调用付费服务。

- `node scripts/check-online-source.cjs --background`：关闭设置后上传 / 下载继续、听歌、任务中心暂停与重启后按歌曲恢复。
- `node scripts/check-background-ui.cjs`：导入及导出在关闭窗口后继续，完整 ZIP 音频 / 中文校验。
- `node scripts/check-lyric-settings.cjs --text --background`：AI 窗口隐藏后继续，原草稿可回到任务中心核对保存，重启不自动重发。
- 单元测试核对任务唯一性、服务启动失败清理、批量暂停、源 / 曲库变化阻止写入、任务日志无密钥、检查点恢复及失败不冒充完成。

安卓编译与模拟原生接口测试不等于手机实测。当前未连接安卓设备，仍需真机验证锁屏传输、切应用、通知暂停、网络切换、后台时限以及不同手机的电池策略。
