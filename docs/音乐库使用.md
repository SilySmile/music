# 音乐库路径与切换

Windows 默认将应用数据保存在安装目录旁的 Data，音乐库通常在 `Data/音乐库`。音乐、封面、原文歌词、中文译文与翻译缓存都保留在本机。安卓使用应用私有数据库，换设备前请导出音乐 ZIP；卸载或清理安卓应用数据前务必备份。

## 打开已有库

1. 打开「偏好设置 → 音乐库保存路径 → 打开已有音乐库」。
2. 选择含 library.json 的完整音乐库目录，也可选择其 Data 父目录。
3. 核对实际路径和歌曲数，点击「校验并切换到已有音乐库」。
4. 软件暂停播放，核验音频 / 封面的大小及 SHA-256，通过后切换并刷新页面。

切换不复制、不合并、不覆盖两个库，也不会恢复目标 Data 中的播放器设置或密钥。原库完整保留，可再次选择切回。新库采用它自己的歌词、收藏及翻译缓存；不会混入当前设备遗留 IndexedDB 的数据。

目录缺失、损坏、缓存格式不符、包含链接或校验期间发生变化时不切换。已配置音乐库丢失清单时不会创建替代空库，可恢复原磁盘或选择另一份有效库。操作前完成传输并退出使用同一库的其他播放器。

「选择新保存位置 → 复制并切换音乐库」是另一个功能，用于将当前库复制到空目录，校验后切换，旧目录保留。更换音乐库不会移动当前播放器设置、系统加密 API Key 或传输记录。

## 保留哪些文件

library.json 是完整索引，含歌曲信息、收藏、歌词与时间轴；translations-cache.json 保存翻译缓存，不含 API Key。「歌曲」目录保存原音频、封面以及可见的 LRC / TXT 和中文副本。下载歌词、AI 翻译及人工修订会在保存后写入；直接编辑副本不会自动同步索引，应通过软件核对表修改或重新导入。

如果当前库位于 release 或 win-unpacked 等构建目录中，该 Data 已是实际用户数据，不能随安装包一起清理。应先通过软件复制迁移到稳定目录并校验，确认后再整理旧路径。

普通音频文件夹、网易云或 QQ 音乐私有数据库不是这种完整文件库。普通歌曲 / 歌词请使用「单独导入音频」「单独导入歌词」或 ZIP 导入，不要手工伪造 library.json。
