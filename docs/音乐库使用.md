# 音乐库路径与切换

Windows 默认将应用数据保存在安装目录旁的 Data，音乐库通常在 `Data/音乐库`。音乐、封面、原文歌词、中文译文与翻译缓存都保留在本机。安卓默认保留原有内部数据库，v1.0.2 起可显示地址、复制到自选文件夹并打开已有文件音乐库。

## 安卓：地址与自选目录

在「偏好设置 → 音乐库保存路径」查看当前地址与歌曲数，自选库还显示系统授权的 content URI，可点击「复制地址」。内部数据库是系统管理的 WebView 存储，不是可以直接用文件管理器打开的音频目录；显示私有数据目录，不伪造数据库文件的完整路径。

首次将现有手机库搬出：

1. 点「复制到自选目录」，在系统文件选择器中选择父目录并允许读写。
2. 建议选择手机或 SD 卡的 Music / Documents 下专用子目录。软件创建“弦栖霁音乐库”，目标已存在时拒绝覆盖。
3. 确认后保持应用前台，复制原音频、封面、双语歌词、收藏及翻译缓存，逐文件 SHA-256 核验后才切换。
4. 原内部数据库不删除，可在设置展开「内部设置、旧库与后台播放副本」，点击「切回保留的内部曲库」。两个库不会自动同步。

后续重启直接读取所选文件库，无需重复导入。已有目录包含 `library.json` 和“歌曲”子目录时，点「打开已有音乐库」即可核验并直接切换，不复制、不合并。也支持选择它的 Data / 父目录，自动识别唯一的“音乐库”或“弦栖霁音乐库”子目录。PC 的完整文件音乐库复制到手机后也可这样打开；ZIP 或仅有 MP3 / LRC 的普通文件夹仍需首次导入。不要同时在多个播放器中修改同一份库。

授权持久保存在系统中，配置位于应用私有 `files/config/library-location.json`。目录被移动、删除或授权撤销时会报错，不会创建替代空库或静默导入旧库；重新选择原目录可恢复。切换不移动当前加密 API Key、偏好或传输记录；传输任务按曲库隔离显示，未完成任务需切回所属库继续。复制失败不切换，目标可能含部分文件，并标记为未完整复制，不能冒充完整曲库打开；应保留原库，另选空位置重试。

Android 11 及以上限制选择存储根目录、Download 根目录及 Android/data、Android/obb，具体可选范围由系统文件选择器决定；使用系统目录授权，不请求“管理所有文件”。见 [Android 官方目录访问说明](https://developer.android.com/training/data-storage/shared/documents-files)。云盘或不支持随机读写 / 安全改名的文件提供器不受支持，请选择手机本地或存储卡目录。

公共目录中的文件库不会随卸载删除，重装后需要再次授权目录；内部曲库、设置、私钥解密所需系统密钥和未另存的导出文件仍会随清理数据 / 卸载丢失。后台播放仍准备并复用 `files/playback-audio` 音频副本，需要额外空间。换设备建议完整复制文件库或导出 ZIP 备份，API Key 需重新填写。

## 打开已有库

1. 打开「偏好设置 → 音乐库保存路径 → 打开已有音乐库」。
2. 选择含 library.json 的完整音乐库目录，也可选择其 Data 父目录。
3. 核对实际路径和歌曲数，点击「校验并切换到已有音乐库」。
4. 软件暂停播放，核验音频 / 封面的大小及 SHA-256，通过后切换并刷新页面。

切换不复制、不合并、不覆盖两个库，也不会恢复目标 Data 中的播放器设置或密钥。原库完整保留，可再次选择切回。新库采用它自己的歌词、收藏及翻译缓存；不会混入当前设备遗留 IndexedDB 的数据。

目录缺失、损坏、缓存格式不符、包含链接或校验期间发生变化时不切换。已配置音乐库丢失清单时不会创建替代空库，可恢复原磁盘或选择另一份有效库。操作前完成传输并退出使用同一库的其他播放器。

「选择新保存位置 → 复制并切换音乐库」是另一个功能，用于将当前库复制到空目录，校验后切换，旧目录保留。更换音乐库不会移动当前播放器设置、系统加密 API Key 或传输记录。

## 保留哪些文件

### 安全移出、重复导入和长列表

- 「全部歌曲」和「最近播放」不提供删除曲库文件的按钮。「我喜欢」中的「移出我喜欢」仅取消收藏，音频、封面、歌词、译文和播放队列均保留；也不会删除云端文件。
- 导入 ZIP 或单独音频时，先读取完整音频并计算 SHA-256；相同内容即使改名也视作同一首，直接返回已有歌曲并将该导入项记为成功，不重写已有文件、歌词或收藏。同名但音频内容不同不误合并。另行补充歌词请用「单独导入歌词」。
- 手动上传也先校验完整音频；服务器已有并核验通过时返回已有歌曲，成功但不重复传音频、不覆盖歌曲信息。已开启的自动上传仍会核对、补充新歌词和译文，复用相同音频文件。
- 列表不超过 200 首时整页展示，超过时每页显示 100 首，限制同时挂载的歌曲行和封面图片。搜索覆盖整个已连接曲库，「播放全部」和播放队列仍包含全部搜索结果，不局限当前页。这不是内存用量的硬上限，曲库索引和歌词元数据仍需内存。
- 云端点播缓存使用当前设置中的本地音乐库；校验完整后保存音频、封面和歌词并变为本地歌曲，不另设长期音频缓存目录。安卓后台播放沿用下文已有的系统播放副本，不是第二份可选曲库。

library.json 是完整索引，含歌曲信息、收藏、歌词与时间轴；translations-cache.json 保存翻译缓存，不含 API Key。「歌曲」目录保存原音频、封面以及可见的 LRC / TXT 和中文副本。下载歌词、AI 翻译及人工修订会在保存后写入；直接编辑副本不会自动同步索引，应通过软件核对表修改或重新导入。

如果当前库位于 release 或 win-unpacked 等构建目录中，该 Data 已是实际用户数据，不能随安装包一起清理。应先通过软件复制迁移到稳定目录并校验，确认后再整理旧路径。

普通音频文件夹、网易云或 QQ 音乐私有数据库不是这种完整文件库。普通歌曲 / 歌词请使用「单独导入音频」「单独导入歌词」或 ZIP 导入，不要手工伪造 library.json。
