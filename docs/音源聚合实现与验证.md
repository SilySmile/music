# 在线音源与曲库边界

Windows 与安卓直接通过各自原生网络层调用 QQ 音乐、网易云接口，不需要额外部署账号聚合网关。个人服务器仅负责已完成下载的普通音频和曲库数据。浏览器预览不提供账号登录、播放和下载。

搜索结果保存在页面内存。每次播放按平台歌曲 ID 获取新地址，不把临时音频地址、Cookie 或令牌存入最近播放。HTML 音频实际 `playing` 后或安卓原生播放器真正开始播放后记录最近播放。安卓服务另行保存最近播放元数据，以恢复锁屏切歌记录。

我的音乐只包含本地曲库和个人服务器的已提交歌曲。在线歌曲使用独立稳定标识，下载完成后以文件 SHA-256 作为曲库标识；最近播放关联到保存的音频后合并显示。同一字节内容重复下载保留原有收藏与歌词。在线播放不触发个人服务器缓存或上传。

# 账号与传输

二维码由平台创建，用户在官方 App 确认。会话由 Windows safeStorage 或 Android Keystore 加密保存，网页只接收删去凭据的状态响应。退出登录删除当前设备的会话，不注销其他设备；无法解密时可清除本机登录状态后重新扫码。

QQ 音乐在原生层通过官方 MQTT 5 / WebSocket 通道接收扫码、取消和授权推送，再调用正式登录接口兑换凭据。单独调用 CheckQRCode 不能可靠接收手机确认，不能据此判断用户尚未扫码。网页每秒查询本机推送状态；订阅成功后才展示二维码，连接失败会提示刷新。安卓网络使用 OkHttp，Windows 使用内置 WebSocket，消息长度与属性均有边界检查。

网易云扫码使用 `interfacepc.music.163.com/eapi` 的二维码接口，原生层保存设备标识与服务端 Cookie。801 表示等待扫码，802 表示已扫码待确认，803 后必须另行验证账号资料；800 表示过期。8821 等其他返回码显示明确错误并停止该二维码轮询，避免手机已经确认后界面仍无限等待。服务端要求额外验证时不会跳过验证。二维码默认最长等待 15 分钟，期间以平台过期状态为准。

平台 API 地址固定，媒体下载只接受对应平台的 HTTPS 域名，并逐跳验证重定向。服务层限制 JSON 响应为 4 MB、单首下载为 200 MB。下载由原生进程写入私有临时文件，再分块交给网页核对格式、时长和文件指纹。长度校验可发现传输中断；元数据校验不等于对每一帧做完整解码。

下载开始时固定曲库范围与服务器目标；提交前核对当前曲库，上传每一步核对目标和凭据。切换目标会停止提交，避免写入错误服务器。网页后台暂停时原生传输可继续；进程被系统终止后任务标为中断，需要重新下载，不提供跨进程续传。

QQ 下载保守要求 `pay_down === 0`，付费歌曲可按实际账号权限尝试播放。网易云调用下载专用接口。返回试听或平台加密格式时拒绝导出，不提供绕过权限、解密或替代音源。

在线结果可单独预览 LRCLIB 匹配歌词。在线播放会把匹配到的时间轴歌词放入现有播放器歌词面板，下载时也把该歌词随曲目保存；歌曲及歌词匹配不到时仍可播放或下载。下载请求优先指定普通 128 kbps MP3，入库前检查实际音频容器和编码；非 MP3、加密或无效内容会拒绝入库，绝不通过改文件扩展名冒充转换。歌词和转换失败都不会产生半成品入库。

# 验证入口

- `npm test`：平台响应、试听拒绝、下载校验、取消、最近播放合并等单元测试。
- `node --test scripts/check-provider-native.cjs`：原生网络层凭据删减与加密、重启、退出竞态、下载重定向与长度、取消及临时文件清理。
- `node scripts/check-providers.cjs`：真实 Electron IPC、系统加密、本地文件曲库、真实个人曲库服务器；仅在平台 HTTP 边界替换响应，以稳定覆盖登录到入库的完整操作。
- `node scripts/check-android-playback-ui.cjs`：模拟安卓桥，检查原生进度、前后台恢复、平台 ID 队列、原生最近播放补齐与布局。
- 安卓 `testReleaseUnitTest` 与编译：验证原生协议构造、域名隔离、播放检查点等。

真实接口已验证 QQ/网易云搜索与播放地址、两者二维码创建、QQ 实时推送订阅与扫码确认、正式凭据兑换、真实账号 info/retCode 资料校验、登录后普通音频下载及进程重启登录恢复。QQ 下载端已切换为显式 MP3 文件请求；网易云请求 128 kbps MP3。需再次通过真实账号验证发布版本的网易云授权与实际 MP3 返回。安卓设备特有行为仍需要真机验收，模拟桥测试不代表真机验收。

协议参考与许可证随 Windows/安卓包内 `provider-notices.txt` 提供。

# v1.0.24 使用调整

服务器自动保存改为设置开关，默认关闭，仅作用于个人服务器歌曲；私密歌曲关闭时读取校验音频用于当次播放，不入本地曲库。安卓播放服务仍可能使用必要的播放缓存。当前队列可编辑并同步安卓后台；自定义歌单按本机音乐库保存歌曲标识和必要的在线歌曲元数据，不保存临时媒体 URL 或账号凭据。

歌曲列表与在线结果按滚动追加加载。定位会切换到全部歌曲或最近播放、清除搜索并加载到当前歌曲。在线搜索历史按平台保存在本机，可清空。

安卓二维码可保存到相册、打开官方 App 或分享给其他设备展示；官方扫一扫是否能从相册识别取决于官方 App。返回前台时立即恢复授权轮询。仅 Android 9 及更早版本保存相册需写入权限，新版使用 MediaStore。没有真机连接，不能将模拟安卓桥验证视为实际相册和官方 App 端到端验收。
