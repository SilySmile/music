弦栖霁 v1.0.23

新增 QQ 音乐与网易云音乐聚合，同时修复安卓后台播放进度与误缩放。本版可覆盖安装旧版。

1. 在线搜索：在独立入口选择 QQ 音乐或网易云音乐，按歌名、歌手搜索并在线播放。账号在各设备单独扫码登录，Windows 使用系统加密存储，安卓使用 Keystore；账号凭据不进入网页、导出包或个人曲库服务器。

QQ 扫码接入官方实时推送，显示已扫码、等待手机确认和登录成功；确认后在原生层兑换并保存登录凭据。修复真实账号资料返回在 info 字段时被误判未登录的问题。

更新网易云二维码登录接口，保留本机设备标识和平台下发的会话。修复平台返回登录方式错误时仍显示“等待授权”的问题，失败会明确提示并停止旧二维码检测。

2. 最近播放与音乐库分开：实际开始播放的在线歌曲进入最近播放，可再次播放；搜索结果与在线播放不会自动加入我的音乐。安卓服务记录锁屏播放历史，回到前台后补齐。

3. 显式下载：选择保存到本地音乐库或已配置的个人服务器，核对平台下载权限后下载普通音频。传输长度、音频格式、时长与 SHA-256 校验通过并完成保存后才入库。相同音频去重并保留已有收藏与歌词。失败、取消、试听片段和加密音频不会入库。单首上限 200 MB；进程终止后需要重新下载。

4. 安卓后台进度：原生播放服务每两秒保存一次，暂停、定位完成与服务正常退出时额外保存。返回前台以原生进度为准；重开同一曲库恢复已保存位置并保持暂停，点击播放继续。系统强杀时恢复到最近一次落盘位置。

5. 安卓防误缩放：安装端关闭网页双指与双击缩放，防止滑动时误放大；普通浏览器仍可缩放。

可播放、可下载范围取决于平台返回的地址及账号权限。QQ 目前只导出平台明确标记可直接下载的普通音频；网易云使用独立下载接口，未登录或无权限时提示登录/权限错误。本版不处理平台加密文件。

验证包括真实搜索、QQ 实时扫码登录、登录后普通音频下载与进程重启登录恢复，以及完整客户端自动化测试（账号会话、播放记录隔离、本地与个人服务器入库、去重、取消、目标切换、重启恢复）、安卓编译和 JVM 测试、安卓桥前后台与布局测试。安卓未连接真机，锁屏与系统省电行为仍需在实际设备验收。
