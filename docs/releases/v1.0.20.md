弦栖霁 v1.0.20

本版针对「安卓每次进入音乐库都要重新读取文件、很慢」做了无感化处理，安装方式不变。

1. 打开即可见：上次的音乐库列表（含封面与歌词）保存在应用私有缓存中，启动时先立即显示，再到后台核对文件夹变化。手机上不再出现每次都等一遍「正在读取文件音乐库 1 / 300」。

2. 曲库索引只读一次：以前一次启动会读取并解析整份 library.json 三次（信息、检查、列表）。现在按文件大小与修改时间判断是否变化，未变化时复用上一次结果。

3. 启动信息不再解析整库：仅需歌曲数与曲库标识，改为缓存摘要；library.json 未变时只查一次文件状态，不读取整份 JSON。

4. 封面缓存到应用私有目录：重复启动不再逐张从手机文件夹读取封面，改为读私有缓存；缓存超过约 128 MB 时自动清理最旧的封面。

5. 兼容性：切换音乐库后旧缓存会被识别为其他曲库而忽略；后台核对完成后用最新结果替换并更新缓存，删除或新增的歌曲会在核对后出现。
