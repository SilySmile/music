弦栖霁 v1.0.21

本版修复安卓播放进度保存与页面误缩放，支持覆盖安装。

1. 后台进度保存：由安卓原生播放服务每两秒保存歌曲、进度、时长和所属曲库；暂停、拖动完成与服务正常退出时额外保存。回到前台后立即核对原生进度，前台定时同步，避免一直显示播放前的位置。

2. 重开继续听：服务仍在运行时连接正在播放的歌曲；冷启动时恢复同一曲库中已保存的歌曲与位置，保持暂停，点击播放后继续。切换曲库或歌曲已删除时忽略无效记录。系统强杀时恢复到最近一次已落盘的位置。

3. 防误缩放：安卓安装端关闭双指和双击网页缩放，避免滑动时误放大导致无法操作。普通浏览器页面保留缩放能力。

4. 启动状态修正：旧曲库快照不再覆盖已经刷新完成的列表；网页音频的旧定位事件不再覆盖原生播放器进度。

验证包括单元测试、安卓编译与 JVM 测试、模拟安卓桥的前后台同步和冷启动恢复，以及桌面播放与曲库回归。未连接安卓真机；请安装后重点检查锁屏播放、后台返回、暂停重开以及双指/双击操作。

QQ 音乐与网易云聚合仍在开发，未包含在本版。后续按已确认规则实现：在线播放可进入最近播放，只有完整保存到本地或个人服务器后才进入我的音乐。
