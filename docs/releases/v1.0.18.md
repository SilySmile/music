弦栖霁 v1.0.18

针对红米安卓「下载 / 补充到本地退后台后进度不动，回前台继续」：已选择手机文件夹时，整批下载改为原生 Java 队列执行，不再由 WebView 逐块发请求。网络、校验、写库、逐首检查点和通知进度在原生线程运行，继续保存到当前授权音乐库，不修改曲库路径、不迁移或重新导入歌曲。

已有相同音频不重复下载，只补缺失封面、原文及匹配的中文；本地已有译文、收藏、加入时间和有效时间轴保留。提交时重新核对曲库身份和最新本地信息。断网或暂停保留完成歌曲，未完成歌曲重试校验；检查点不保存访问密钥。

本版同步发布 PC 安装包、便携版和安卓 APK，沿用原安卓签名及更新验签密钥。当前完成 JVM 原生队列、前端及编译测试，没有连接红米手机实测。默认内部 IndexedDB 库和其他类别尚未全部原生化，不承诺锁屏下全部任务均可继续。系统强杀、移除最近任务、后台时限、失去目录授权等仍可能中断，需手动继续。

安装前暂停旧下载，直接覆盖安装，不要卸载。测试步骤见 docs/后台任务说明.md。
