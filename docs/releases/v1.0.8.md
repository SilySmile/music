弦栖霁 v1.0.8

修复 Windows 点击「退出并安装」后，安装向导进行到一半退出的问题。旧流程从程序目录下的 Data/Updates 直接运行安装包；播放器进程尚未完全退出时，安装器的进程检查可能将安装包本身也纳入关闭范围。

新版播放器先将已验证的安装包复制到安装目录之外的独立系统临时目录，重新核验长度和 SHA-256，通过后再显示安装向导并退出播放器。启动失败则保留播放器和下载文件，允许重试，避免重复点击启动多个安装器。目标路径参数支持中文和空格，保持当前安装目录。

本次安装包也包含旧版升级兼容：即使仍由旧播放器从 Data/Updates 启动，也会先将自身转到临时目录，并保留原始安装参数，再继续安装。无需先手动升级更新器。临时副本准备失败会提示具体环节，不删除原安装包。

继续沿用原应用 ID、签名和数据保留方式；不删除 Data、音乐库、歌词、收藏或 AI 配置，不变更当前音乐库路径。

验证包括签名清单与安装包校验、安装启动失败时不退出、重复安装拦截，以及隔离目录中的真实 NSIS 回归：模拟播放器子进程仍在退出，复现旧流程的安装器自匹配，验证旧版启动和新版临时副本两条路径均能继续完成，中文和空格目标路径、原下载包和数据哨兵文件均保留。未在实际用户音乐库上执行测试安装，安卓仍需真机验证。
