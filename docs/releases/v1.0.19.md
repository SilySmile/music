弦栖霁 v1.0.19

本版集中修复 8 个使用问题，PC 安装包、便携版与安卓 APK 同步发布，安装方式不变。

1. 安卓进入文件曲库更快：启动时不再逐首查询系统文件夹（300 首约省去 900 次目录查询）。文档地址在导入时写入曲库索引，旧库首次启动自动补齐一次；封面改为并发读取。

2. 传输任务都能删除：以前只有「已完成」的任务有删除按钮，暂停、失败、待核对的任务无法清理。现在非运行中的任务都可删除，只删除任务记录和检查点，不会删除已下载的歌曲。

3. 首次后台播放不再等待整库复制：文件夹曲库的歌曲直接以系统文档地址交给原生播放器，不再把整个播放队列复制到应用私有目录；仅内部曲库仍需复制，分块从 1 MiB 提高到 4 MiB。播放可立即交给前台播放服务，锁屏与切后台继续由该服务负责。

4. 云端「下载 / 补充」明显加快：同一首已完成歌曲不再回读整个音频重新校验，也不再重写曲库索引与歌词文件；一批任务内复用已解析的索引。全选补充一个没有变化的曲库时接近空操作。

5. 支持同时进行两个下载 / 补充任务：新建任务前先比对本地，已有音频、封面和中文歌词的歌曲自动跳过；超过两个任务会明确提示，等待或到任务中心暂停其中一个即可。设置页不再因为一个任务在跑就整页禁用。

6. 安卓切后台 / 锁屏停止播放：与第 3 条同源，播放不再等待 WebView 复制队列，开始播放后即由 mediaPlayback 前台服务接管。该项仍需真机确认，本版未连接手机实测。

7. 随机播放不再反复几首：改为洗牌袋，一轮内每首播放一次后才重新洗牌，桌面与安卓原生播放都生效。

8. 歌曲列表补全状态：每首歌继续标注「云端 / 本地」，需要补充的歌曲新增「需补充」角标并记住状态；连接云端音乐后自动比对并启动一个补充任务，跳过本地已完整的内容，可在「传输任务」查看或暂停。

自动验证：Vitest 212 项、Android JVM 单元测试、TypeScript 编译与打包流程通过；安卓锁屏连播、文件选择与系统覆盖安装仍需在手机上确认。升级前请从托盘退出旧版，安装新包不会删除 Data、音乐库或 AI 配置。
