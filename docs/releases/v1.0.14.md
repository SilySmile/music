弦栖霁 v1.0.14

新增「本地强对齐（音频 + 原歌词）」方式，地址、模型名称和密钥独立于翻译服务。可导入本机生成的连接配置、测试连接，并使用系统加密保存两个服务的密钥；本地强对齐无需先配置聊天模型。

手动模式支持本句、整首缺失补齐和整首重新生成，已有错误逐字时间和唱完位置可以重算。结果先作为草稿，试听并保存后写入增强 LRC 和曲库。保留原文、中文与未匹配的原时间，继续区分唱完时间与后续间奏。

默认手动。桌面端可主动开启自动本地强对齐，最多两首并发，可降到一首。自动只处理缺失或旧聊天 AI 估算的时间，已有有效实测时间跳过；有效结果直接保存。Windows 主机和服务端均检查资源，服务停止或资源紧张时等待；失败记录按歌曲、模型和曲库保留，避免重试风暴，可手动重试。编辑、导入或切换曲库时暂停，未保存的取消结果不落盘。

部署助手、说明、配置模板与服务源代码集中在项目 local-aligner 目录。它复用现有 Qwen3-ForcedAligner-0.6B 权重，以 vLLM 0.20.2 的 token classification 能力运行音频+原文专用服务，不需另下 ASR 模型。一次准备后用启动和停止脚本控制，无开机自启，空闲默认十分钟退出；CPU、内存、显存预算、批次和队列均有限制。本机生成的密钥、Linux 磁盘、日志和缓存均保留在该目录 runtime，不提交或上传。

限制：当前开发电脑未安装 WSL，真实 GPU 模型推理尚未实测，不能把接口测试当成模型准确率验证；首次使用需按 local-aligner/README.md 完成 WSL 准备，可能需要 Windows 重启。强对齐主要基于语音训练，复杂伴奏或错误歌词版本仍需试听校准。

验证包含单元测试、十项服务协议/资源策略测试、Windows 脚本的隔离 WSL 替身测试、真实 Electron 与本机 HTTP 的配置导入/加密恢复、手动保存与取消、两首并发、资源不足零音频上传、已有实测跳过、旧估算替换、未匹配检查点与重启、明确重试及移动布局。没有调用用户付费服务或修改现有模型文件。
