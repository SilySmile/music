弦栖霁 v1.0.17

统一后台任务：上传、下载 / 补充到本地、导入、导出及已经手动启动的歌词翻译和逐字处理，关闭任务窗口后继续，可以继续听歌和操作其他页面。任务中心统一查看进度、暂停、恢复和返回原窗口；逐字处理仍先生成草稿，核对保存后才写入音乐库。

安卓增加独立 dataSync 前台服务、任务通知和 CPU 唤醒锁，支撑已启动任务在正常锁屏、切换应用后继续；全部任务结束后停止服务。首次使用请允许通知，必要时通过任务中心打开系统电池设置并允许后台运行。已完成原生编译、单元及隔离界面回归，目前没有连接手机实测厂商锁屏与后台策略。

音源上传和下载保存当前音乐库、音源身份及逐首完成检查点，暂停或重启后手动恢复，已完成歌曲跳过。当前未完成的下载歌曲重新读取并校验，不是单首文件字节级续传。下载、封面和歌词仍保存在设置中当前选择的本地音乐库，不新增长期音频缓存目录，不迁移或删除已有曲库。

隐藏任务窗口不再渲染大型歌曲列表，隐藏任务中心停止重复查询，工作任务继续。联网歌词和翻译绑定启动时的歌曲，播放切歌不串写译文。更新下载、目录复制、点播缓存及主动开启的本地强对齐纳入任务进度管理，切换库和音源时避开相关活动任务。

限制：真正退出或强制停止程序、系统杀进程、从最近任务划除、失去文件授权、网络中断及厂商省电策略仍可能中止任务。Android 的 dataSync 系统时限到达后停止服务并请求暂停，检查点保留。安卓导出最后的系统另存位置选择仍需返回前台操作。未保存的 AI 草稿不承诺跨进程恢复；付费 AI 请求不会因重启自动重发，已提交请求可能仍计费。

详细使用与恢复方式见 docs/后台任务说明.md。
