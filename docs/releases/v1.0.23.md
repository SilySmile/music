弦栖霁 v1.0.23

新增在线搜索歌词预览与在线歌词显示，下载端优先请求普通 MP3。继续包含 v1.0.22 的安卓播放进度保存、防误缩放及 QQ 音乐和网易云音乐聚合功能。

1. 在线搜索结果提供歌词预览。在线播放时匹配时间轴歌词并显示在现有播放器歌词面板；找不到歌词时仍可正常播放。

2. 下载音频时同时保存匹配歌词。曲库只有在音频完整、格式及时间长度校验通过后才会加入。

3. 下载优先请求 QQ 音乐 128 kbps MP3 与网易云 128 kbps MP3。保存前检查实际编码和容器；平台未提供 MP3、返回试听片段、无效或加密内容时停止入库，不通过更改扩展名伪装转换，也不绕过平台保护。

4. 网易云二维码登录改用当前 eapi 请求，登录拒绝会明确提示，不再无限等待。QQ 保持本机扫码授权和加密会话保存。

验证包含前端单元测试、完整 Electron 账号/播放/歌词/下载入库流程、安卓协议构造与 JVM 测试、发布流水线回归。真实账号最终扫码和网易云 MP3 返回仍需在正式发布前实测；安卓锁屏及省电行为仍需真机验收。
