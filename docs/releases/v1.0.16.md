弦栖霁 v1.0.16

本地强对齐支持多轮补齐。第一轮检查整首待处理歌词，后续只给未通过的句子改变音频前文上下文，最多尝试五种不同策略；已通过的逐字时间保留，全部通过就结束。显示轮次、通过与剩余句数，策略耗尽仍不通过的句子保留原时间并显示待复核原因。单字拖音、句内停顿、整句唱完后的间奏分别保留，不把末字拖长到下一句。

自动模式继续最多两首并发，每首只预处理一次音频。资源不足或服务停止时保存已通过结果，恢复后继续剩余句子；手动结果仍为草稿，点击保存才生效，取消不保存本次结果。多种上下文重复到相同音频范围时不再次推理，不无限空转，不放宽原文、字序、时间边界和模型分数阈值凑满通过。旧失败记录在升级后按新策略再尝试。

歌曲标题与歌手组成的信息行、录音及混音等明确署名行会跳过，不计入演唱句失败；单独出现的歌名仍可作为唱词处理。《慕夏》此前 51 条输入中的两条未通过项实际是歌曲标题及录音署名，不能据此说两句唱词对齐失败。

增强 LRC 的估算时间标记改为逐句保存，避免部分旧估算与新强对齐结果混合时，重新导入把已处理句子也标成估算。继续读取旧版整首估算标记，不改动现有音频和模型权重。

本机外部模型服务代码已同步，并完成真实 CUDA 的五种上下文、字间停顿、句尾静音、双请求并发和两个 59 秒片段的批次测试，峰值 CUDA 分配约 2.35GB。其他电脑需同步 local-aligner 部署目录并重启服务，播放器安装包不修改外部模型目录。

限制：通过指原文、字序和时间范围校验通过，不等于逐字贴合程度已经人工试听确认。模型对同一输入不会因反复调用自行学习；五种策略仍失败时需核对原句范围、歌词版本或手动校准。
