弦栖霁 v1.0.24

1. 偏好设置新增「播放个人服务器歌曲时自动下载到本地」开关，默认关闭。开启后仅保存播放过的服务器歌曲，关闭会停止未完成的自动保存，保留已有歌曲。QQ 音乐和网易云仍需手动下载。私密服务器歌曲需读取完整音频用于播放；安卓后台播放可能使用独立播放缓存。

2. 我的音乐、收藏、最近播放和在线搜索改为滚动到底部继续加载，追加结果保留之前的歌曲。在线加载失败可以点击重试。

3. 歌曲列表新增当前歌曲定位，播放器中点击歌名也可以跳回当前歌曲；自动清除筛选并加载歌曲所在位置，在线歌曲定位到最近播放。

4. 播放队列支持添加、上移、下移、移除和清空待播。安卓同步更新后台队列，保留仍在队列中的当前歌曲和播放进度。新增多个自定义歌单的创建、重命名、删除、歌曲增删排序和整单播放；歌单按本地音乐库保存到本设备，移除歌曲和删除歌单不会删除音乐文件。

5. 在线搜索增加固定搜索框、清除输入、按平台保存的最近搜索和历史清空；适配手机键盘搜索与操作区域。搜索结果可以直接加入队列。

6. 安卓登录支持保存二维码到相册并打开对应官方 App，或分享二维码到另一台设备。官方 App 的扫一扫支持相册识别时可在同一台手机完成授权；返回播放器后立即核验登录。若官方 App 不支持识别该二维码，仍需另一设备展示二维码。凭据继续仅在本机加密保存。

验证覆盖前端单元测试、曲库滚动加载与定位、歌单重启恢复、服务器下载开关、在线搜索失败重试及安卓桥回归，另含安卓编译和 JVM 测试。安卓实体设备的相册保存、官方 App 扫码识别和系统锁屏行为尚需真机确认。
