弦栖霁 v1.0.9

修正 v1.0.8 在旧版播放器内点击「退出并安装」仍会中途关闭的问题。播放器将 TEMP/TMP 重定向到安装目录内的 Data/Temp，导致上一版的安装临时副本与 old-uninstaller.exe 实际仍处于程序目录内，安装器关闭旧进程时可能把它们一起结束。

新版安装包通过 Windows 已知文件夹接口取得独立临时目录，重新启动安装器之前同时设置 TEMP/TMP，让安装器、插件和旧卸载器都在程序目录之外运行。旧版播放器直接启动新版安装包也会走这条兼容流程，无需先手动安装中间版本。

新版播放器在重定向普通缓存目录之前保留系统临时目录，更新时使用该目录创建经过 SHA-256 校验的安装副本，并为子进程单独传入 TEMP/TMP；普通播放器数据仍保存在原 Data 目录中。保留当前安装位置、音乐库、歌词、收藏、AI 设置及原更新下载包。

新增完整 NSIS 升级回归，采用随机应用 ID/GUID、独立测试目录及无害测试程序：先安装 1.0.6，再从 Data/Updates 启动更新并继承 Data/Temp，复现 1.0.8 中途退出，然后验证修正版完成旧版卸载、文件替换、后续更新与最终卸载，检查中文及空格路径、Data 和原安装包保留。该回归加入正式发布检查，不会操作真实播放器安装或用户音乐库。安卓未改功能，仍需真机验证。
