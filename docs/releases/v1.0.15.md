弦栖霁 v1.0.15

修复本地强对齐整首检查后只有少数句子通过的问题。原始时间有效时直接保留；遇到时间交叉或零时长，从同次推理的时间分类分数中寻找符合字序、时长为正且留在原句范围内的路径。调整范围和分数差有限制，分数不足的句子仍保留原时间，不把歌词均分到间奏中。

手动生成与自动处理显示当前歌曲已检查和通过的句数。手动完成时列出未通过句子的具体原因；自动处理显示累计生成、未通过句数及需检查歌曲数量。内部两句微批次不是每首只能生成两句，所有待处理句子都会检查。

减少微批次固定等待，共享最多一秒的资源采样，保留最多两首并发和原有 CPU、内存、显存及温度保护。升级后允许旧失败项重新尝试一次，已有有效逐字时间继续跳过，仍失败的句子不会自动循环重试。

本地模型部署已经切换为 Windows 原生 PyTorch / Transformers，无需 WSL。模型权重、启动脚本、配置、环境和日志集中在 E:\work\model；这台电脑的服务代码已同步，其他机器需要同步 local-aligner 部署目录并重启服务，播放器安装包不会修改外部模型目录。

本机《慕夏》51 句的只读真实模型测试，边界与字序校验通过数从 25 句提高到 49 句，另 2 句保留原时间；模型已加载时的实际接口请求约 3 秒。通过数不等同于人工听辨准确率，首次加载和其他歌曲耗时不同。另验证真实 CUDA 的字间停顿、句尾静音、双请求并发及两个 59 秒片段的批次，峰值 CUDA 分配约 2.35GB。复杂伴奏、合唱或错误歌词版本仍需试听确认。
