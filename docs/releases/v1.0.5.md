弦栖霁 v1.0.5

云端听歌：设置中填写服务器地址即可连接已开启公开读取的曲库，上传密钥可留空；云端歌曲直接合并到全部歌曲，同音频优先使用本地版本。点播时通过 HTTPS 流播放，只缓存听过的歌曲，完整校验后将音频、封面、原文和中文歌词保存到当前配置的本地音乐库，不另建长期云端音频缓存目录。已经缓存的歌曲可离线播放。

安全操作：全部歌曲和最近播放移除文件删除入口；我喜欢中的移出操作只取消收藏，不删音频、歌词、播放队列或云端文件。导入 ZIP / 单独音频按完整 SHA-256 去重，改名的同音频直接返回已有歌曲并计为成功，不重写已有文件和译文。手动上传也先校验，线上已有且通过核验时直接成功返回，不重复传输或覆盖；自动上传仍可补充后续保存的歌词与译文。

长列表：200 首以内保持单页，超过时每页渲染 100 行，减少同时挂载的歌曲行和封面。搜索覆盖全部曲库，播放全部和队列不受分页限制。曲库索引与歌词元数据仍占内存，不承诺无限容量。

PC 更新：安装器改为可见向导，不再使用隐藏静默安装参数。旧版自身的更新启动逻辑需先升级一次；如首次升级未出现安装窗口，请从本次发布下载 Windows 安装包并手动运行。安装与卸载仍保留 Data 和音乐库。

安卓播放：云端歌曲加入原生后台播放队列，不预下载所有云端音频。系统挂起 WebView 时，已听歌曲的本地曲库缓存可能等待回到前台后完成；后台播放仍复用既有播放副本。已通过构建、JVM 与模拟目录测试，尚未安卓真机验证锁屏、授权和系统覆盖安装。

服务端：新增明确开启的公开读取和 HTTPS Range 流接口；知道公开地址的人可读取全部歌曲、封面及歌词，上传、修改与上传检查点仍受写入密钥保护。关闭公开读取不能收回已下载副本。部署保留现有歌曲、密钥和历史修订，不修改独立的软件更新签名身份。

升级前请从托盘退出旧播放器并备份音乐库；安卓请直接覆盖安装，不要先卸载或清除数据。Windows 安装包仍未配置商业代码签名证书。安装包、源码与 GitHub 发布不包含用户音乐库、密钥或服务器管理凭据。
