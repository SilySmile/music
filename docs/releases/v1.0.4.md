弦栖霁 v1.0.4

新增：一键连接私人在线曲库，自动核对并上传当前本地库的全部歌曲、封面、原文歌词和已保存的中文译文。后续导入、联网歌词和 AI 翻译保存后自动排队上传；文件传输不额外调用 AI。

安全核对：相同音频按 SHA-256 去重，服务器核验实际文件内容；相同歌曲信息不重复上传。同步检查点按曲库、服务器和访问凭证隔离；两端并发修改或首次遇到不同歌词、译文、封面时保留两端，列出待处理歌曲，不强制覆盖。不自动删除任一端歌曲，不自动下载线上独有歌曲。

恢复与操作：自动上传支持暂停、断网重试、分块恢复和重启后继续；PC 关闭设置仍继续上传，安卓需保持应用前台，回到前台后恢复。旧配置不擅自开启，需点击“一键连接并自动上传”。支持导入私人连接配置，系统加密保存曲库密钥，不上传 AI 密钥、播放器配置或播放历史。

安卓曲库：设置可查看实际地址、复制内部曲库到自选公共目录，或直接打开已有 PC 兼容文件库，避免反复导入。原库保留，切换需授权并核验。未连接安卓真机，本版文件授权、锁屏和系统安装仍需设备验证。

部署与发布：增加已有 HTTPS 更新服务器的一键在线曲库部署包，重复部署保留原数据和密钥；开发电脑可一键测试、打包、沿用原签名并发布 PC/APK，支持失败续发。修复 Windows 发布入口编码切换导致命令被截断的问题。

升级前请从托盘退出旧播放器并备份音乐库；安卓请勿先卸载，以免删除应用私有数据。Windows 安装包未配置商业代码签名证书。音乐库、服务器管理凭据和私钥不包含在安装包或 GitHub 发布资源中。
